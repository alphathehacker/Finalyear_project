# Finalyear_project — early prototype

> **This is the early prototype (Oct 2025) of my final-year project. The final version is [counselling-assistant](https://github.com/alphathehacker/counselling-assistant).**

An admission/college predictor built with React + Vite (Rocket/Dhiwise scaffold): students enter exam/rank details and get college predictions from cutoff data, with an Express backend.

I kept this repo because its commit history shows how the project actually evolved — from this prototype into the finished Counselling Assistant. For the current code, features and setup instructions, use the final repo linked above.
